# Night Watch

An example project for Luna: a small night-sky viewer concept. The illustration and short video below demonstrate how media appears inside the terminal.

## Features

- A quiet night scene with a crescent moon and reflected starlight.
- A short animated view of the landscape.
- Inline media that stays inside the terminal window.
- Video playback using the keyboard or native player controls.
